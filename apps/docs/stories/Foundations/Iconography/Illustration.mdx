# Ilustrações

Ilustrações e elementos gráficos do Ciberso-UI Design System.

## Visão Geral

As ilustrações no Ciberso-UI são usadas para:

- **Estados Vazios**: Quando não há conteúdo para exibir
- **Onboarding**: Guias e tutoriais
- **Feedback Visual**: Reforçar mensagens e estados
- **Identidade Visual**: Identidade visual do sistema

## Princípios de Ilustração

### 1. Simplicidade
Ilustrações devem ser simples e diretas, evitando detalhes desnecessários.

### 2. Consistência
Mantenha um estilo visual consistente em todas as ilustrações.

### 3. Acessibilidade
Sempre forneça texto alternativo para ilustrações informativas.

### 4. Escalabilidade
Use formatos vetoriais (SVG) para garantir qualidade em qualquer tamanho.

## Diretrizes de Uso

### Estados Vazios

Ilustrações para estados vazios devem ser:
- **Claras**: Comunicar claramente o estado
- **Acolhedoras**: Não parecer um erro
- **Acionáveis**: Sugerir próximos passos quando apropriado

```tsx
// Exemplo de Estado Vazio com ilustração
<div className="empty-state">
  <IllustrationEmptyState className="w-48 h-48" />
  <h3>Nenhum item encontrado</h3>
  <p>Comece adicionando seu primeiro item</p>
  <Button>Adicionar Item</Button>
</div>
```

### Onboarding

Ilustrações de onboarding devem:
- **Guiar**: Mostrar o caminho para o usuário
- **Educar**: Explicar funcionalidades
- **Motivar**: Encorajar o uso

### Estados de Erro

Ilustrações de erro devem:
- **Comunicar**: Deixar claro que algo deu errado
- **Não assustar**: Manter tom profissional
- **Orientar**: Sugerir soluções quando possível

## Estilos de Ilustração

### Arte em Linha
Ilustrações em estilo linha, minimalistas e limpas.

### Design Plano
Ilustrações planas com cores sólidas, sem gradientes complexos.

### Isométrico
Ilustrações isométricas para elementos 3D quando necessário.

## Boas Práticas

1. **Use ilustrações com propósito** - Não adicione apenas por estética
2. **Mantenha consistência** - Use o mesmo estilo em todo o sistema
3. **Otimize para performance** - Comprima SVGs e use lazy loading
4. **Teste em diferentes tamanhos** - Garanta legibilidade em mobile e desktop
