# Fontes de Ícones

Fontes de ícones utilizadas no Ciberso-UI Design System.

## Visão Geral

O Ciberso-UI utiliza **Material Icons (Filled style)** do Google Fonts como fonte principal de ícones.

## Material Icons

### Fonte
- **Provedor**: Google Fonts
- **Estilo**: Filled
- **URL**: https://fonts.google.com/icons?icon.set=Material+Icons&icon.style=Filled

### Características

- **Estilo Consistente**: Todos os ícones seguem o mesmo estilo visual
- **Biblioteca Abrangente**: Mais de 2000 ícones disponíveis
- **Otimizado**: SVGs otimizados para performance
- **Acessível**: Suporte completo a acessibilidade

## Implementação

Os ícones são convertidos de SVG para componentes React no pacote `@ciberso/icons`:

```tsx
// Importação
import { Add, Delete, Close } from '@ciberso/icons';

// Uso
<Add className="w-5 h-5" />
```

## Formato de Ícones

### Componentes SVG
Todos os ícones são componentes React que renderizam SVG:

```tsx
// Estrutura interna
export const Add = (props: SVGProps<SVGSVGElement>) => (
  <svg {...props} viewBox="0 0 24 24" fill="currentColor">
    <path d="M19 13h-6v6h-2v-6H5v-2h6V5h2v6h6v2z" />
  </svg>
);
```

### Benefícios

- **Tree-shaking**: Apenas ícones usados são incluídos no bundle
- **Customizável**: Fácil customizar cor e tamanho via props
- **Type-safe**: TypeScript completo para autocomplete
- **Performance**: SVGs otimizados e comprimidos

## Nomenclatura de Ícones

Os ícones seguem a convenção de nomenclatura do Material Icons:

- **PascalCase**: `Add`, `Delete`, `ArrowForward`
- **Descritivo**: Nomes que descrevem claramente o ícone
- **Consistente**: Mesma convenção para todos os ícones

## Exemplos de Uso

### Com Botões

```tsx
<Button leftIcon={<Add className="w-4 h-4" />}>
  Adicionar
</Button>
```

### Apenas Ícone

```tsx
<Button iconOnly rightIcon={<Close className="w-5 h-5" />} aria-label="Fechar" />
```

### Com Texto

```tsx
<div className="flex items-center gap-2">
  <Check className="w-5 h-5 text-green-500" />
  <span>Item adicionado com sucesso</span>
</div>
```

## Boas Práticas

1. **Sempre defina tamanho** - Use classes Tailwind (`w-4 h-4`, `w-5 h-5`, etc.)
2. **Mantenha consistência** - Use o mesmo tamanho de ícone em contextos similares
3. **Considere acessibilidade** - Adicione `aria-label` quando necessário
4. **Otimize imports** - Importe apenas os ícones que você usa

## Adicionando Novos Ícones

Para adicionar novos ícones ao sistema:

1. Obtenha o SVG do Material Icons
2. Execute o script de build do pacote `@ciberso/icons`
3. O ícone será automaticamente convertido em componente React
4. Exporte no `index.ts` do pacote
