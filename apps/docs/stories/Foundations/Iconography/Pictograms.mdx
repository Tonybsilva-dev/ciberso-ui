# Pictogramas

Pictogramas e símbolos do Ciberso-UI Design System.

## Visão Geral

Os pictogramas são símbolos visuais simples e diretos que representam ações, objetos ou conceitos. No Ciberso-UI, utilizamos Material Icons (Filled style) como base do sistema de ícones.

## Biblioteca de Ícones

O pacote `@ciberso/icons` fornece uma biblioteca completa de ícones SVG otimizados e convertidos em componentes React.

### Ícones Disponíveis

Os ícones estão disponíveis através do pacote `@ciberso/icons`:

```tsx
import { Add, Delete, Close, Check, ArrowForward } from '@ciberso/icons';

// Uso em componentes
<Button leftIcon={<Add className="w-4 h-4" />}>
  Adicionar
</Button>
```

## Diretrizes de Uso

### 1. Sempre defina tamanho explícito

```tsx
// ✅ DO: Tamanho explícito
<Add className="w-5 h-5" />

// ❌ DON'T: Sem tamanho definido
<Add />
```

### 2. Use ícones consistentemente

- **Ações primárias**: Use ícones que representem claramente a ação
- **Navegação**: Use ícones direcionais (ArrowForward, ArrowBack)
- **Estados**: Use ícones que indiquem o estado (Check, Close, Error)

### 3. Mantenha acessibilidade

```tsx
// ✅ DO: Com aria-label quando necessário
<Button iconOnly rightIcon={<Add className="w-5 h-5" />} aria-label="Adicionar item" />

// ✅ DO: Ícone decorativo com aria-hidden
<span aria-hidden="true">
  <Check className="w-4 h-4" />
</span>
```

## Categorias de Ícones

### Ações
- Add, Delete, Edit, Save, Search
- Usados para ações do usuário

### Navegação
- ArrowForward, ArrowBack, ArrowUp, ArrowDown
- Usados para navegação e direção

### Status
- Check, Close, Error, Warning, Info
- Usados para feedback e estados

### Conteúdo
- File, Folder, Image, Video
- Usados para tipos de conteúdo

## Boas Práticas

1. **Use ícones com propósito** - Cada ícone deve ter um significado claro
2. **Mantenha consistência** - Use o mesmo estilo de ícone em todo o sistema
3. **Considere contexto** - O mesmo ícone pode ter significados diferentes em contextos diferentes
4. **Teste acessibilidade** - Sempre verifique com screen readers
