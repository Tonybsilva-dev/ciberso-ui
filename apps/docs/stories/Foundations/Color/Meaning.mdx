# Color Meaning

Significado e uso de cada cor no Ciberso-UI Design System.

## Ciberso Theme Colors

### Cyan (#00F6FF)
**Significado**: Energia, tecnologia, inovação
**Uso**: 
- Elementos de destaque tecnológico
- Ícones e acentos
- Estados ativos e hover em elementos especiais

### Royal Blue (#007BFF)
**Significado**: Confiança, profissionalismo, ação
**Uso**:
- Botões primários
- Links e ações principais
- Elementos de navegação importantes
- Estados de foco

### Dark Blue (#0A192F)
**Significado**: Profundidade, estabilidade, fundação
**Uso**:
- Backgrounds de seções
- Headers e footers
- Elementos estruturais profundos

### Gold (#FFD700)
**Significado**: Premium, valor, conquista
**Uso**:
- Elementos premium
- Badges de conquista
- Destaques especiais
- Elementos de destaque limitado

### Black (#000000)
**Significado**: Contraste, definição, clareza
**Uso**:
- Textos principais
- Bordas e divisores
- Elementos de alto contraste

## Semantic Colors

### Success (#00F6FF - Cyan)
**Significado**: Sucesso, conclusão, positivo
**Uso**:
- Mensagens de sucesso
- Estados concluídos
- Feedback positivo

### Error (#FF4444)
**Significado**: Erro, alerta, atenção necessária
**Uso**:
- Mensagens de erro
- Validações negativas
- Estados críticos

### Warning (#FF9500)
**Significado**: Aviso, atenção, cuidado
**Uso**:
- Mensagens de aviso
- Estados de atenção
- Alertas não críticos

### Info (#007BFF - Royal Blue)
**Significado**: Informação, orientação, contexto
**Uso**:
- Mensagens informativas
- Tooltips e hints
- Contexto adicional

## UI Component Colors

### Primary Button
Representa a ação principal em uma interface. Deve ser usado com parcimônia para destacar a ação mais importante.

### Secondary Button
Representa ações secundárias ou alternativas. Usado para ações que não são a principal, mas ainda são importantes.

### Input States
Cores que indicam o estado dos campos de entrada:
- **Border**: Estado padrão
- **Border Focused**: Campo ativo/focado
- **Border Error**: Campo com erro de validação
- **Background Disabled**: Campo desabilitado

## Tag Colors

Cores para categorização e organização de conteúdo:

- **Orange**: Avisos e alertas
- **Blue**: Informações e links
- **Green**: Sucesso e confirmação
- **Red**: Erros e remoção

## Guidelines

1. **Use cores consistentemente** - Cada cor tem um propósito específico
2. **Respeite o significado** - Não use cores fora de contexto
3. **Mantenha a hierarquia** - Cores primárias para ações principais
4. **Considere acessibilidade** - Sempre verifique contraste
