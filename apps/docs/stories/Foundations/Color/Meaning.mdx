# Color Meaning

Significado e uso de cada cor no Ciberso-UI Design System, inspirado no **Cloude**.

## Primary Theme Colors

### Background (#faf9f5)
**Significado**: Base, neutralidade, elegância
**Uso**: 
- Fundo principal de páginas e layouts
- Base para containers e seções
- Background padrão do sistema
**Classe Tailwind**: `bg-background`

### Foreground (#3d3929)
**Significado**: Conteúdo, legibilidade, hierarquia
**Uso**:
- Textos principais e títulos
- Elementos de alto contraste
- Conteúdo primário
**Classe Tailwind**: `text-foreground`

### Primary (#c96442)
**Significado**: Ação, destaque, importância
**Uso**:
- Botões primários
- Links e ações principais
- Elementos de navegação importantes
- Estados de foco e ativos
**Classe Tailwind**: `bg-primary`, `text-primary`, `border-primary`

### Primary Foreground (#ffffff)
**Significado**: Contraste, clareza, legibilidade
**Uso**:
- Texto em botões primários
- Ícones em elementos primary
- Conteúdo sobre backgrounds primary
**Classe Tailwind**: `text-primary-foreground`

## Secondary & Accent Colors

### Secondary (#e9e6dc)
**Significado**: Apoio, alternância, suavidade
**Uso**: 
- Botões secundários
- Ações alternativas
- Elementos de apoio visual
**Classe Tailwind**: `bg-secondary`, `text-secondary`

### Accent (#e9e6dc)
**Significado**: Destaque, atenção, interação
**Uso**:
- Elementos de destaque
- Hover states
- Estados de seleção
**Classe Tailwind**: `bg-accent`, `text-accent`

## UI Component Colors

### Card (#faf9f5)
**Significado**: Organização, agrupamento, estrutura
**Uso**:
- Containers de conteúdo
- Cards informativos
- Agrupamento visual
**Classe Tailwind**: `bg-card`, `text-card-foreground`

### Muted (#ede9de)
**Significado**: Subtileza, desativação, hierarquia secundária
**Uso**:
- Elementos secundários
- Estados desabilitados
- Backgrounds sutis
**Classe Tailwind**: `bg-muted`, `text-muted-foreground`

### Popover (#ffffff)
**Significado**: Elevação, foco, contexto
**Uso**:
- Tooltips e popovers
- Menus suspensos
- Informações contextuais
**Classe Tailwind**: `bg-popover`, `text-popover-foreground`

## Status & Feedback Colors

### Destructive (#141413)
**Significado**: Perigo, erro, ação destrutiva
**Uso**:
- Botões de remoção
- Mensagens de erro
- Estados críticos
- Validações negativas
**Classe Tailwind**: `bg-destructive`, `text-destructive`, `border-destructive`

**Nota**: A cor destructive usa um tom escuro (#141413) para criar contraste adequado com texto branco, garantindo acessibilidade e legibilidade.

## Sidebar & Navigation Colors

### Sidebar Background (#f5f4ee)
**Significado**: Navegação, estrutura, organização
**Uso**: Fundo de sidebars e painéis de navegação

### Sidebar Primary (#c96442)
**Significado**: Navegação ativa, destaque, contexto
**Uso**: Itens de navegação ativos na sidebar

### Sidebar Accent (#e9e6dc)
**Significado**: Hover, interação, feedback
**Uso**: Estados de hover na sidebar

## Utility & Form Colors

### Border (#dad9d4)
**Significado**: Separação, definição, estrutura
**Uso**:
- Bordas de componentes
- Divisores visuais
- Separadores de conteúdo
**Classe Tailwind**: `border-border`

### Input (#b4b2a7)
**Significado**: Interação, entrada de dados, formulários
**Uso**:
- Bordas de inputs
- Estados padrão de formulários
- Campos de texto
**Classe Tailwind**: `border-input`

### Ring (#c96442)
**Significado**: Foco, atenção, interação ativa
**Uso**:
- Anéis de foco (focus-visible)
- Estados ativos
- Indicadores de interação
**Classe Tailwind**: `ring-ring`, `focus-visible:ring-ring`

## Diretrizes

1. **Use cores consistentemente** - Cada cor tem um propósito específico
2. **Respeite o significado** - Não use cores fora de contexto
3. **Mantenha a hierarquia** - Cores primárias para ações principais
4. **Considere acessibilidade** - Sempre verifique contraste
5. **Prefira classes Tailwind** - Use `bg-primary` em vez de valores hardcoded
6. **Adapte-se ao tema** - As cores se ajustam automaticamente em modo claro/escuro

## Princípios de Design

O sistema de cores do Ciberso-UI é baseado nos seguintes princípios:

- **Consistência**: Cores têm significados claros e consistentes
- **Acessibilidade**: Todas as combinações atendem WCAG 2.1 AA
- **Hierarquia**: Cores primárias destacam ações importantes
- **Flexibilidade**: Suporte a temas claro e escuro
- **Modernidade**: Uso de OKLCH para melhor percepção de cores
