# Color

A paleta de cores do Ciberso-UI Design System é inspirada no **Cloude**, criando uma identidade visual única, elegante e consistente.

## Visão Geral

O sistema de cores do Ciberso-UI segue o padrão **shadcn/ui** e é organizado em categorias principais:

- **Primary Theme Colors**: Cores principais do tema (background, foreground, primary, secondary)
- **UI Component Colors**: Cores específicas para componentes (card, popover, muted, accent)
- **Status & Feedback Colors**: Cores semânticas para feedback (destructive, success, warning, info)
- **Chart & Visualization Colors**: Cores para gráficos e visualizações
- **Sidebar & Navigation Colors**: Cores para navegação e sidebars
- **Utility & Form Colors**: Cores utilitárias (border, input, ring)

## Estrutura

Esta seção contém as seguintes páginas:

- **Palettes**: Visualização completa de todas as paletas de cores
- **Contrast**: Guias de contraste e acessibilidade
- **Meaning**: Significado e uso de cada cor
- **Swatches**: Amostras interativas de cores

## Sistema de Cores

O Ciberso-UI utiliza **variáveis CSS** com valores **OKLCH** para garantir:
- Consistência visual em diferentes dispositivos
- Melhor percepção de cores uniforme
- Suporte a temas claro e escuro
- Compatibilidade com padrões modernos de design

Todas as cores são acessíveis via classes Tailwind CSS (ex: `bg-primary`, `text-foreground`, `border-border`).
