# Color

A paleta de cores do Ciberso-UI Design System é inspirada no arquétipo Ciberso de Yu-Gi-Oh, criando uma identidade visual única e consistente.

## Visão Geral

O sistema de cores do Ciberso-UI é organizado em três categorias principais:

- **Ciberso Colors**: Paleta temática principal (cyan, royalBlue, darkBlue, gold, black)
- **Semantic Colors**: Cores semânticas para feedback (success, error, warning, info)
- **UI Colors**: Cores específicas para componentes (primary, secondary, input, tag)

## Estrutura

Esta seção contém as seguintes páginas:

- **Palettes**: Visualização completa de todas as paletas de cores
- **By Category**: Cores organizadas por categoria e uso
- **Contrast**: Guias de contraste e acessibilidade
- **Meaning**: Significado e uso de cada cor
- **Swatches**: Amostras interativas de cores
