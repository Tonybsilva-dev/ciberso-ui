# Cores

A paleta de cores do Ciberso-UI Design System é inspirada no **Cloude**, criando uma identidade visual única, elegante e consistente.

## Visão Geral

O sistema de cores do Ciberso-UI segue o padrão **shadcn/ui** e é organizado em categorias principais:

- **Cores Principais do Tema**: Cores principais do tema (background, foreground, primary, secondary)
- **Cores de Componentes UI**: Cores específicas para componentes (card, popover, muted, accent)
- **Cores de Status e Feedback**: Cores semânticas para feedback (destructive, success, warning, info)
- **Cores de Gráficos e Visualizações**: Cores para gráficos e visualizações
- **Cores de Barra Lateral e Navegação**: Cores para navegação e sidebars
- **Cores Utilitárias e de Formulário**: Cores utilitárias (border, input, ring)

## Estrutura

Esta seção contém as seguintes páginas:

- **Paletas**: Visualização completa de todas as paletas de cores
- **Contraste**: Guias de contraste e acessibilidade
- **Significado**: Significado e uso de cada cor
- **Amostras**: Amostras interativas de cores

## Sistema de Cores

O Ciberso-UI utiliza **variáveis CSS** com valores **OKLCH** para garantir:
- Consistência visual em diferentes dispositivos
- Melhor percepção de cores uniforme
- Suporte a temas claro e escuro
- Compatibilidade com padrões modernos de design

Todas as cores são acessíveis via classes Tailwind CSS (ex: `bg-primary`, `text-foreground`, `border-border`).
