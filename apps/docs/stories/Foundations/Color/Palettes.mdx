# Color Palettes

Visualização completa de todas as paletas de cores do Ciberso-UI Design System.

## Ciberso Theme Colors

### Cyan

A cor ciano neon (#00F6FF) é a cor primária do tema Ciberso, representando energia e tecnologia.

<div style={{ display: 'grid', gridTemplateColumns: 'repeat(5, 1fr)', gap: '1rem', marginTop: '2rem' }}>
  {Object.entries(colors.ciberso.cyan).map(([key, value]) => (
    <div key={key} style={{ textAlign: 'center' }}>
      <div
        style={{
          width: '100%',
          height: '80px',
          backgroundColor: value,
          borderRadius: '8px',
          border: key === '500' ? '2px solid #000' : '1px solid #e5e7eb',
          marginBottom: '0.5rem',
        }}
      />
      <div style={{ fontSize: '12px', fontWeight: 'bold' }}>{key}</div>
      <div style={{ fontSize: '11px', color: '#6b7280' }}>{value}</div>
    </div>
  ))}
</div>
