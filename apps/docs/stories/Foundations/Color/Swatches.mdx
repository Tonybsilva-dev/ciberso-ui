# Color Swatches

Amostras interativas de todas as cores do Ciberso-UI Design System, inspirado no **Cloude**.

## Primary Theme Colors

<div style={{ display: 'grid', gridTemplateColumns: 'repeat(auto-fill, minmax(200px, 1fr))', gap: '1rem', marginTop: '1rem' }}>
  {[
    { name: 'Background', color: '#faf9f5', textColor: '#3d3929' },
    { name: 'Foreground', color: '#3d3929', textColor: '#ffffff' },
    { name: 'Primary', color: '#c96442', textColor: '#ffffff' },
    { name: 'Primary Foreground', color: '#ffffff', textColor: '#3d3929' },
  ].map((swatch) => (
    <div
      key={swatch.name}
      style={{
        padding: '1.5rem',
        backgroundColor: swatch.color,
        borderRadius: '8px',
        border: '1px solid #dad9d4',
        cursor: 'pointer',
        textAlign: 'center',
        transition: 'transform 0.2s, box-shadow 0.2s',
      }}
      onMouseEnter={(e) => {
        e.currentTarget.style.transform = 'scale(1.02)';
        e.currentTarget.style.boxShadow = '0 4px 12px rgba(0,0,0,0.1)';
      }}
      onMouseLeave={(e) => {
        e.currentTarget.style.transform = 'scale(1)';
        e.currentTarget.style.boxShadow = 'none';
      }}
      onClick={() => {
        navigator.clipboard.writeText(swatch.color);
        alert(`Cor ${swatch.color} copiada para a área de transferência!`);
      }}
    >
      <div style={{ fontSize: '16px', fontWeight: 'bold', color: swatch.textColor, marginBottom: '0.5rem' }}>
        {swatch.name}
      </div>
      <div style={{ fontSize: '14px', color: swatch.textColor, opacity: 0.9, marginBottom: '0.25rem' }}>
        {swatch.color}
      </div>
      <div style={{ fontSize: '12px', color: swatch.textColor, opacity: 0.7 }}>
        Clique para copiar
      </div>
    </div>
  ))}
</div>

## Uso

Clique em qualquer cor para copiar seu valor hexadecimal para a área de transferência.

Todas as cores também estão disponíveis como classes Tailwind CSS (ex: `bg-primary`, `text-foreground`, `border-border`).
