# Color Swatches

Amostras interativas de todas as cores do Ciberso-UI Design System.

## Interactive Color Picker

Selecione uma cor para ver seus detalhes e valores.

<div style={{ marginTop: '2rem' }}>
  <h3>Ciberso Theme Colors</h3>
  <div style={{ display: 'grid', gridTemplateColumns: 'repeat(auto-fill, minmax(120px, 1fr))', gap: '1rem', marginTop: '1rem' }}>
    {Object.entries(colors.ciberso).map(([colorName, colorScale]) => (
      <div key={colorName} style={{ border: '1px solid #e5e7eb', borderRadius: '8px', overflow: 'hidden' }}>
        <div style={{ padding: '0.5rem', backgroundColor: '#f9fafb', borderBottom: '1px solid #e5e7eb' }}>
          <div style={{ fontSize: '12px', fontWeight: 'bold', textTransform: 'capitalize' }}>{colorName}</div>
        </div>
        {Object.entries(colorScale).map(([key, value]) => (
          <div
            key={key}
            style={{
              display: 'flex',
              alignItems: 'center',
              padding: '0.5rem',
              backgroundColor: value,
              cursor: 'pointer',
              transition: 'opacity 0.2s',
            }}
            onMouseEnter={(e) => {
              e.currentTarget.style.opacity = '0.8';
            }}
            onMouseLeave={(e) => {
              e.currentTarget.style.opacity = '1';
            }}
            onClick={() => {
              navigator.clipboard.writeText(value);
              alert(`Cor ${value} copiada para a área de transferência!`);
            }}
          >
            <div style={{ flex: 1, fontSize: '11px', fontWeight: 'bold', color: parseInt(key) >= 500 ? '#fff' : '#000' }}>
              {key}
            </div>
            <div style={{ fontSize: '10px', color: parseInt(key) >= 500 ? '#fff' : '#000', opacity: 0.8 }}>
              {value}
            </div>
          </div>
        ))}
      </div>
    ))}
  </div>
</div>
