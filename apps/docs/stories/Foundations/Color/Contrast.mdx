# Color Contrast

Guias de contraste e acessibilidade para garantir legibilidade em todos os contextos.

## WCAG 2.1 AA Compliance

Todas as combinações de cores do Ciberso-UI seguem os padrões WCAG 2.1 AA:

- **Texto normal**: Contraste mínimo de 4.5:1
- **Texto grande (18px+)**: Contraste mínimo de 3:1
- **Componentes UI**: Contraste mínimo de 3:1

## Best Practices

1. **Sempre use cores com contraste adequado** para textos e elementos interativos
2. **Teste combinações** antes de usar em produção
3. **Use ferramentas de contraste** para validar acessibilidade
4. **Evite combinações de baixo contraste** mesmo em elementos decorativos
