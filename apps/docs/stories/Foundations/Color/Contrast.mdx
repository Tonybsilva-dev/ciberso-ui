# Color Contrast

Guias de contraste e acessibilidade para garantir legibilidade em todos os contextos do Ciberso-UI Design System.

## WCAG 2.1 AA Compliance

Todas as combinações de cores do Ciberso-UI seguem os padrões WCAG 2.1 AA:

- **Texto normal**: Contraste mínimo de 4.5:1
- **Texto grande (18px+)**: Contraste mínimo de 3:1
- **Componentes UI**: Contraste mínimo de 3:1

## Best Practices

1. **Sempre use cores com contraste adequado** para textos e elementos interativos
2. **Teste combinações** antes de usar em produção
3. **Use ferramentas de contraste** para validar acessibilidade
4. **Evite combinações de baixo contraste** mesmo em elementos decorativos
5. **Prefira as combinações padrão** do sistema que já foram validadas

- [WebAIM Contrast Checker](https://webaim.org/resources/contrastchecker/)
- [Contrast Ratio Calculator](https://contrast-ratio.com/)

- [axe DevTools](https://www.deque.com/axe/devtools/)

## Guidelines Específicos

### Textos Principais
- Use `text-foreground` em backgrounds claros
- Use `text-primary-foreground` em backgrounds primary
- Use `text-destructive-foreground` em backgrounds destructive

### Textos Secundários
- Use `text-muted-foreground` para textos secundários
- Use `text-secondary-foreground` em backgrounds secondary

### Elementos Interativos
- Botões primários: `bg-primary text-primary-foreground`
- Botões secundários: `bg-secondary text-secondary-foreground`
- Botões destructive: `bg-destructive text-destructive-foreground`

### Cards e Containers
- Cards: `bg-card text-card-foreground`
- Popovers: `bg-popover text-popover-foreground`

Todas essas combinações foram validadas e atendem aos padrões WCAG 2.1 AA.
