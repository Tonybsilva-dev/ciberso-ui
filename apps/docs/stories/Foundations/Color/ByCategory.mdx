# Color by Category

Cores organizadas por categoria e uso no Design System.

## Primary Colors

Cores primárias do tema Ciberso, usadas para elementos principais e ações.

### Deep Blue (#007BFF)
Cor primária para botões, links e elementos de ação principais.

### Ciano Neon (#00F6FF)
Cor de destaque e elementos tecnológicos.

### Crisp Black (#111827)
Cor para textos e elementos de alto contraste.

### White (#FFFFFF)
Cor para backgrounds e textos em fundos escuros.
