# Color by Category

Cores organizadas por categoria e uso no Design System Ciberso-UI, inspirado no **Cloude**.

## Primary Theme Colors

Cores principais do tema, usadas para elementos fundamentais da interface.

### Background (#faf9f5)
Cor de fundo principal da interface. Fornece a base neutra e elegante para todo o design.

**Uso:**
- Fundo principal de páginas e layouts
- Base para containers e seções
- Background padrão do sistema

**Classe Tailwind:** `bg-background`

### Foreground (#3d3929)
Cor principal para textos e elementos de primeiro plano.

**Uso:**
- Textos principais e títulos
- Elementos de alto contraste
- Conteúdo primário

**Classe Tailwind:** `text-foreground`

### Primary (#c96442)
Cor primária do sistema, usada para ações principais e elementos de destaque.

**Uso:**
- Botões primários
- Links e ações principais
- Elementos de navegação importantes
- Estados de foco e ativos

**Classe Tailwind:** `bg-primary`, `text-primary`, `border-primary`

### Primary Foreground (#ffffff)
Cor de texto para elementos com background primary.

**Uso:**
- Texto em botões primários
- Ícones em elementos primary
- Conteúdo sobre backgrounds primary

**Classe Tailwind:** `text-primary-foreground`

Cor para anéis de foco e estados ativos.

**Uso:**

**Classe Tailwind:** `ring-ring`, `focus-visible:ring-ring`

## Guidelines de Uso

1. **Use cores consistentemente** - Cada cor tem um propósito específico
2. **Respeite a hierarquia** - Cores primárias para ações principais
3. **Mantenha contraste adequado** - Sempre verifique acessibilidade
4. **Prefira classes Tailwind** - Use `bg-primary` em vez de valores hardcoded
5. **Considere temas claro/escuro** - As cores se adaptam automaticamente
