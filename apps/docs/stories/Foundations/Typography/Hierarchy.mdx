# Hierarquia Tipográfica

Hierarquia tipográfica e uso de tamanhos no Ciberso-UI Design System.

## Tamanhos de Fonte

Escala modular de tamanhos de fonte disponíveis:

<div style={{ display: 'flex', flexDirection: 'column', gap: '2rem', marginTop: '2rem' }}>
  {Object.entries(typography.sizes).map(([key, value]) => {
    const sizeInPx = parseFloat(value) * 16; // Converter rem para px
    return (
      <div key={key} style={{ borderBottom: '1px solid #dad9d4', paddingBottom: '1rem' }}>
        <div style={{ display: 'flex', alignItems: 'baseline', gap: '2rem' }}>
          <div style={{ minWidth: '100px' }}>
            <div style={{ fontSize: '12px', fontWeight: 'bold', color: '#83827d', textTransform: 'uppercase' }}>
              {key}
            </div>
            <div style={{ fontSize: '11px', color: '#83827d', marginTop: '0.25rem' }}>
              {value} ({sizeInPx}px)
            </div>
          </div>
          <div style={{ flex: 1 }}>
            <div style={{ fontSize: value, lineHeight: typography.lineHeights.normal, fontWeight: typography.weights.normal, color: '#3d3929' }}>
              A rápida raposa marrom pula sobre o cão preguiçoso
            </div>
            <div style={{ fontSize: value, lineHeight: typography.lineHeights.normal, fontWeight: typography.weights.bold, marginTop: '0.5rem', color: '#3d3929' }}>
              A rápida raposa marrom pula sobre o cão preguiçoso (Negrito)
            </div>
          </div>
        </div>
      </div>
    );
  })}
</div>

## Diretrizes de Uso

### Títulos

Use a hierarquia de títulos (H1-H6) para estruturar o conteúdo:

- **H1**: Títulos principais de página (2xl ou 3xl)
- **H2**: Seções principais (xl ou 2xl)
- **H3**: Subseções (lg ou xl)
- **H4-H6**: Níveis menores de hierarquia (md ou lg)

### Texto do Corpo

- **Texto Grande (lg)**: Textos importantes e destaques
- **Texto Médio (md/base)**: Texto padrão para conteúdo
- **Texto Pequeno (sm)**: Textos secundários e rótulos

### Código

Use a fonte monospace para código e elementos técnicos.
