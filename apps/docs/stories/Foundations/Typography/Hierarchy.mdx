# Typography Hierarchy

Hierarquia tipográfica e uso de tamanhos no Ciberso-UI Design System.

## Font Sizes

Escala modular de tamanhos de fonte disponíveis:

<div style={{ display: 'flex', flexDirection: 'column', gap: '2rem', marginTop: '2rem' }}>
  {Object.entries(typography.sizes).map(([key, value]) => {
    const sizeInPx = parseFloat(value) * 16; // Converter rem para px
    return (
      <div key={key} style={{ borderBottom: '1px solid #e5e7eb', paddingBottom: '1rem' }}>
        <div style={{ display: 'flex', alignItems: 'baseline', gap: '2rem' }}>
          <div style={{ minWidth: '100px' }}>
            <div style={{ fontSize: '12px', fontWeight: 'bold', color: '#6b7280', textTransform: 'uppercase' }}>
              {key}
            </div>
            <div style={{ fontSize: '11px', color: '#9ca3af', marginTop: '0.25rem' }}>
              {value} ({sizeInPx}px)
            </div>
          </div>
          <div style={{ flex: 1 }}>
            <div style={{ fontSize: value, lineHeight: typography.lineHeights.normal, fontWeight: typography.weights.normal }}>
              The quick brown fox jumps over the lazy dog
            </div>
            <div style={{ fontSize: value, lineHeight: typography.lineHeights.normal, fontWeight: typography.weights.bold, marginTop: '0.5rem' }}>
              The quick brown fox jumps over the lazy dog (Bold)
            </div>
          </div>
        </div>
      </div>
    );
  })}
</div>

## Usage Guidelines

### Headings

Use a hierarquia de headings (H1-H6) para estruturar o conteúdo:

- **H1**: Títulos principais de página (2xl ou 3xl)
- **H2**: Seções principais (xl ou 2xl)
- **H3**: Subseções (lg ou xl)
- **H4-H6**: Níveis menores de hierarquia (md ou lg)

### Body Text

- **Body Large (lg)**: Textos importantes e destaques
- **Body Medium (md/base)**: Texto padrão para conteúdo
- **Body Small (sm)**: Textos secundários e labels

### Code

Use a fonte monospace para código e elementos técnicos.
