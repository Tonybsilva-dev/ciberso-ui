# Typography

O sistema de tipografia do Ciberso-UI Design System garante consistência e legibilidade em todos os componentes.

## Visão Geral

O sistema de tipografia é baseado em:

- **Hierarquia clara**: Tamanhos e pesos bem definidos
- **Legibilidade**: Line heights e espaçamentos otimizados
- **Consistência**: Uso padronizado de fontes e pesos
- **Acessibilidade**: Tamanhos mínimos e contraste adequado

## Estrutura

Esta seção contém as seguintes páginas:

- **Hierarchy**: Hierarquia tipográfica e uso de tamanhos
- **Weights / Types**: Pesos de fonte e estilos disponíveis
- **Web Fonts**: Fontes web utilizadas no sistema
- **Baseline Grids**: Sistema de grid de baseline para alinhamento
