# Fontes Web

Fontes web utilizadas no Ciberso-UI Design System.

## Pilha de Fontes

O Ciberso-UI utiliza uma pilha de fontes (font stack) otimizada para performance e compatibilidade:

### Sans Serif (Default)

```
{typography.fonts.sans.join(', ')}
```

Esta pilha garante:
- **Inter**: Fonte principal moderna e legível
- **system-ui**: Fallback para fontes do sistema
- **-apple-system**: Fontes do sistema Apple
- **sans-serif**: Fallback genérico

### Monospace (Code)

```
{typography.fonts.mono.join(', ')}
```

Esta pilha garante:
- **JetBrains Mono**: Fonte monospace moderna para código
- **Menlo**: Fallback para sistemas Apple
- **Monaco**: Fallback adicional
- **monospace**: Fallback genérico

## Carregamento de Fontes

### Performance

As fontes são carregadas de forma otimizada:

1. **Font Display**: `swap` para melhor performance
2. **Preload**: Fontes críticas são pré-carregadas
3. **Subset**: Apenas caracteres necessários são incluídos

### Implementação

```css
/* Exemplo de implementação */
@font-face {
  font-family: 'Inter';
  font-style: normal;
  font-weight: 400 700;
  font-display: swap;
  src: url('/fonts/inter.woff2') format('woff2');
}
```

## Suporte de Navegadores

O Ciberso-UI suporta todos os navegadores modernos:

- ✅ Chrome/Edge (últimas 2 versões)
- ✅ Firefox (últimas 2 versões)
- ✅ Safari (últimas 2 versões)
- ✅ Opera (últimas 2 versões)

## Fontes Personalizadas

Para adicionar fontes customizadas ao projeto:

1. Adicione os arquivos de fonte em `/public/fonts/`
2. Configure o `@font-face` no CSS global
3. Atualize os tokens de tipografia se necessário

## Boas Práticas

1. **Use font-display: swap** para melhor performance
2. **Preload fontes críticas** no `<head>`
3. **Subset fontes** para reduzir tamanho
4. **Teste fallbacks** em diferentes sistemas
