# Grids de Baseline

Sistema de grid de baseline para alinhamento vertical consistente no Ciberso-UI Design System.

## Visão Geral

O baseline grid é um sistema invisível de linhas horizontais que ajuda a alinhar elementos verticalmente, criando uma aparência mais organizada e profissional.

## Sistema de Grid

O Ciberso-UI utiliza um sistema de baseline baseado em **4px**, garantindo alinhamento consistente em todos os componentes.

### Escala de Espaçamento

A escala de espaçamento segue múltiplos de 4px:

<div style={{ marginTop: '2rem' }}>
  <div style={{ display: 'grid', gridTemplateColumns: 'repeat(auto-fill, minmax(100px, 1fr))', gap: '1rem' }}>
    {Object.entries({ ...spacing, ...space }).map(([key, value]) => {
      const sizeInPx = parseFloat(value.replace('rem', '')) * 16;
      return (
        <div key={key} style={{ textAlign: 'center' }}>
          <div
            style={{
              width: '100%',
              height: value,
              backgroundColor: '#c96442',
              borderRadius: '4px',
              marginBottom: '0.5rem',
            }}
          />
          <div style={{ fontSize: '12px', fontWeight: 'bold' }}>{key}</div>
          <div style={{ fontSize: '11px', color: '#83827d' }}>{value}</div>
          <div style={{ fontSize: '10px', color: '#83827d' }}>{sizeInPx}px</div>
        </div>
      );
    })}
  </div>
</div>

## Diretrizes de Implementação

### 1. Use Line Heights Múltiplos de 4px

```css
/* ✅ FAÇA: Line heights alinhados ao grid */
.text-base {
  font-size: 16px;
  line-height: 24px; /* 6 × 4px */
}

/* ❌ NÃO FAÇA: Line heights não alinhados */
.text-base {
  font-size: 16px;
  line-height: 23px; /* Não é múltiplo de 4px */
}
```

### 2. Use Espaçamentos Múltiplos de 4px

```css
/* ✅ FAÇA: Espaçamento alinhado ao grid */
.component {
  margin-bottom: 16px; /* 4 × 4px */
  padding: 12px; /* 3 × 4px */
}
```

### 3. Mantenha Consistência Vertical

- Margens entre elementos: múltiplos de 4px
- Padding interno: múltiplos de 4px
- Line heights: múltiplos de 4px

## Benefícios

1. **Consistência Visual**: Elementos alinhados criam uma aparência mais profissional
2. **Legibilidade**: Espaçamento adequado melhora a leitura
3. **Manutenibilidade**: Sistema previsível facilita desenvolvimento
4. **Escalabilidade**: Fácil adicionar novos elementos mantendo o alinhamento
