## Diretrizes de Uso

### Normal (400)
- Texto padrão do corpo
- Conteúdo longo e legível
- Rótulos e descrições

### Medium (500)
- Destaques sutis
- Rótulos importantes
- Elementos de navegação secundários

### Semibold (600)
- Subtítulos
- Destaques moderados
- Elementos de interface importantes

### Bold (700)
- Títulos e headings
- Destaques fortes
- Elementos de ação importantes

## Boas Práticas

1. **Use pesos consistentemente** - Mantenha a hierarquia visual
2. **Evite muitos pesos** - Use no máximo 2-3 pesos por página
3. **Priorize legibilidade** - Normal (400) para textos longos
4. **Destaque com moderação** - Bold (700) apenas para elementos importantes
