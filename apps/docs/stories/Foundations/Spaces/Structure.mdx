# Estrutura de Espaçamento

Estrutura e organização do sistema de espaçamento no Ciberso-UI Design System, inspirado no **Cloude**.

## Hierarquia de Espaçamento

O sistema de espaçamento segue uma hierarquia clara:

### Nível 1: Micro (4-8px)
Espaçamento entre elementos muito próximos:

- Ícone e texto
- Badge e conteúdo
- Elementos inline

### Nível 2: Pequeno (12-16px)
Espaçamento entre elementos relacionados:

- Itens de lista
- Campos de formulário
- Elementos de card

### Nível 3: Médio (24-32px)
Espaçamento entre seções:

- Seções de conteúdo
- Grupos de componentes
- Espaçamento vertical em cards

### Nível 4: Grande (48-64px)
Espaçamento entre áreas principais:

- Seções principais da página
- Espaçamento entre módulos
- Margens de página

  <h3>Padding do Container</h3>

    <div style={{ padding: '1.5rem', backgroundColor: '#ede9de', borderRadius: '4px' }}>

        Padding do container: 32px (8 × 4px)
      </div>
      <div style={{ fontSize: '12px', color: '#83827d', marginTop: '0.25rem' }}>
        Padding do conteúdo: 24px (6 × 4px)

### Estrutura de Grid

Sistema de grid baseado em espaçamento consistente:

<div style={{ marginTop: '2rem' }}>
  <h3>Espaçamento do Grid</h3>
  <div style={{ display: 'grid', gridTemplateColumns: 'repeat(3, 1fr)', gap: '1.5rem', marginTop: '1rem' }}>
    {[1, 2, 3].map((item) => (
      <div key={item} style={{ padding: '1rem', backgroundColor: '#ede9de', borderRadius: '4px', textAlign: 'center', border: '1px solid #dad9d4' }}>
        <div style={{ fontSize: '12px', fontWeight: 'bold', color: '#3d3929' }}>Coluna {item}</div>
        <div style={{ fontSize: '11px', color: '#83827d', marginTop: '0.25rem' }}>
          Gap: 24px (6 × 4px)
        </div>
      </div>
    ))}
  </div>
</div>

## Padrões de Espaçamento de Componentes

### Grupo de Botões

```tsx
// ✅ DO: Espaçamento consistente entre botões
<div className="flex gap-2">
  <Button>Primário</Button>
  <Button variant="secondary">Secundário</Button>
</div>
```

**Espaçamento**: 8px (2 × 4px) entre botões relacionados

### Campos de Formulário

```tsx
// ✅ DO: Espaçamento adequado entre campos
<div className="space-y-4">
  <Input label="Nome" />
  <Input label="Email" />
  <Input label="Senha" />
</div>
```

**Espaçamento**: 16px (4 × 4px) entre campos de formulário

### Conteúdo de Card

```tsx
// ✅ DO: Padding interno consistente
<Card>
  <CardHeader>
    <CardTitle>Título</CardTitle>
  </CardHeader>
  <CardContent>
    {/* Conteúdo com padding de 24px */}
  </CardContent>
</Card>
```

**Espaçamento**: 24px (6 × 4px) padding interno

## Espaçamento Responsivo

### Mobile (< 768px)

- Padding do container: 16px
- Espaçamento entre seções: 24px
- Espaçamento entre componentes: 12-16px

### Tablet (768px - 1024px)

- Padding do container: 24px
- Espaçamento entre seções: 32px
- Espaçamento entre componentes: 16-24px

### Desktop (> 1024px)

- Padding do container: 32px
- Espaçamento entre seções: 48px
- Espaçamento entre componentes: 24-32px

## Relações de Espaçamento

### Proporção Áurea (Opcional)

Para espaçamentos maiores, pode-se usar proporção áurea:

- Base: 16px
- × 1.618 = 26px (≈ 24px)
- × 1.618 = 42px (≈ 40px)
- × 1.618 = 68px (≈ 64px)

### Escala Modular

Escala modular baseada em 4px:

```
4px → 8px → 12px → 16px → 24px → 32px → 48px → 64px
```

Cada valor é múltiplo do anterior ou incremento de 4px.

## Implementação

### Classes Tailwind

```tsx
// Use classes Tailwind que seguem a escala
<div className="p-4">     // 16px
<div className="p-6">     // 24px
<div className="p-8">     // 32px
<div className="gap-2">   // 8px
<div className="gap-4">   // 16px
```

### Espaçamento Customizado

```tsx
// Para espaçamentos customizados, use múltiplos de 4px
<div style={{ padding: '20px' }}>  // 5 × 4px
<div style={{ margin: '28px' }}>    // 7 × 4px
```

## Boas Práticas

1. **Mantenha a hierarquia** - Use espaçamentos maiores para elementos mais importantes
2. **Seja consistente** - Use os mesmos espaçamentos em contextos similares
3. **Considere densidade** - Mobile pode usar espaçamentos menores
4. **Teste visualmente** - Espaçamentos podem parecer diferentes em contextos diferentes
5. **Use o tema** - Aproveite as cores do sistema para representar espaçamentos visualmente
