# Space Structure

Estrutura e organização do sistema de espaçamento no Ciberso-UI Design System.

## Spacing Hierarchy

O sistema de espaçamento segue uma hierarquia clara:

### Level 1: Micro (4-8px)
Espaçamento entre elementos muito próximos:

- Ícone e texto
- Badge e conteúdo
- Elementos inline

### Level 2: Small (12-16px)
Espaçamento entre elementos relacionados:

- Itens de lista
- Campos de formulário
- Elementos de card

### Level 3: Medium (24-32px)
Espaçamento entre seções:

- Seções de conteúdo
- Grupos de componentes
- Espaçamento vertical em cards

### Level 4: Large (48-64px)
Espaçamento entre áreas principais:

- Seções principais da página
- Espaçamento entre módulos
- Margens de página

      </div>
      <div style={{ fontSize: '12px', color: '#6b7280', marginTop: '0.25rem' }}>
        Content padding: 24px (6 × 4px)
      </div>
    </div>
  </div>
</div>

### Grid Structure

Sistema de grid baseado em espaçamento consistente:

<div style={{ marginTop: '2rem' }}>
  <h3>Grid Spacing</h3>
  <div style={{ display: 'grid', gridTemplateColumns: 'repeat(3, 1fr)', gap: '1.5rem', marginTop: '1rem' }}>
    {[1, 2, 3].map((item) => (
      <div key={item} style={{ padding: '1rem', backgroundColor: '#f9fafb', borderRadius: '4px', textAlign: 'center' }}>
        <div style={{ fontSize: '12px', fontWeight: 'bold' }}>Column {item}</div>
        <div style={{ fontSize: '11px', color: '#6b7280', marginTop: '0.25rem' }}>
          Gap: 24px (6 × 4px)
        </div>
      </div>
    ))}
  </div>
</div>

## Component Spacing Patterns

### Button Group

```tsx
// ✅ DO: Espaçamento consistente entre botões
<div className="flex gap-2">
  <Button>Primary</Button>
  <Button variant="secondary">Secondary</Button>
</div>
```

**Spacing**: 8px (2 × 4px) entre botões relacionados

### Form Fields

```tsx
// ✅ DO: Espaçamento adequado entre campos
<div className="space-y-4">
  <Input label="Name" />
  <Input label="Email" />
  <Input label="Password" />
</div>
```

**Spacing**: 16px (4 × 4px) entre campos de formulário

### Card Content

```tsx
// ✅ DO: Padding interno consistente
<Card>
  <CardHeader>
    <CardTitle>Title</CardTitle>
  </CardHeader>
  <CardContent>
    {/* Content with 24px padding */}
  </CardContent>
</Card>
```

**Spacing**: 24px (6 × 4px) padding interno

## Responsive Spacing

### Mobile (< 768px)

- Container padding: 16px
- Section spacing: 24px
- Component spacing: 12-16px

### Tablet (768px - 1024px)

- Container padding: 24px
- Section spacing: 32px
- Component spacing: 16-24px

### Desktop (> 1024px)

- Container padding: 32px
- Section spacing: 48px
- Component spacing: 24-32px

## Spacing Relationships

### Golden Ratio (Optional)

Para espaçamentos maiores, pode-se usar proporção áurea:

- Base: 16px
- × 1.618 = 26px (≈ 24px)
- × 1.618 = 42px (≈ 40px)
- × 1.618 = 68px (≈ 64px)

### Modular Scale

Escala modular baseada em 4px:

```
4px → 8px → 12px → 16px → 24px → 32px → 48px → 64px
```

Cada valor é múltiplo do anterior ou incremento de 4px.

## Implementation

### Tailwind Classes

```tsx
// Use classes Tailwind que seguem a escala
<div className="p-4">     // 16px
<div className="p-6">     // 24px
<div className="p-8">     // 32px
<div className="gap-2">   // 8px
<div className="gap-4">   // 16px
```

### Custom Spacing

```tsx
// Para espaçamentos customizados, use múltiplos de 4px
<div style={{ padding: '20px' }}>  // 5 × 4px
<div style={{ margin: '28px' }}>    // 7 × 4px
```

## Best Practices

1. **Mantenha a hierarquia** - Use espaçamentos maiores para elementos mais importantes
2. **Seja consistente** - Use os mesmos espaçamentos em contextos similares
3. **Considere densidade** - Mobile pode usar espaçamentos menores
4. **Teste visualmente** - Espaçamentos podem parecer diferentes em contextos diferentes
