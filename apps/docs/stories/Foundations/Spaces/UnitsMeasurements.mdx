# Unidades e Medidas

Unidades e medidas do sistema de espaçamento do Ciberso-UI Design System, inspirado no **Cloude**.

## Unidade Base

O sistema utiliza **4px (0.25rem)** como unidade base. Todos os espaçamentos são múltiplos desta unidade.

## Escala de Espaçamento

### Espaçamento Semântico

Espaçamentos semânticos para uso em componentes:

<div style={{ display: 'grid', gridTemplateColumns: 'repeat(4, 1fr)', gap: '1rem', marginTop: '2rem' }}>
  {Object.entries(spacing).map(([key, value]) => {
    const sizeInPx = parseFloat(value.replace('rem', '')) * 16;
    return (
      <div key={key} style={{ textAlign: 'center' }}>
        <div
          style={{
            width: '100%',
            height: value,
            backgroundColor: '#c96442',
            borderRadius: '4px',
            marginBottom: '0.5rem',
            border: '1px solid #dad9d4',
          }}
        />
        <div style={{ fontSize: '12px', fontWeight: 'bold', textTransform: 'uppercase', color: '#3d3929' }}>{key}</div>
        <div style={{ fontSize: '11px', color: '#83827d' }}>{value}</div>
        <div style={{ fontSize: '10px', color: '#83827d' }}>{sizeInPx}px</div>
      </div>
    );
  })}
</div>

## Unidades

### Rem (Recomendado)

Use `rem` para espaçamentos que devem escalar com o tamanho da fonte do usuário:

```css
.component {
  padding: 1rem; /* 16px */
  margin: 0.5rem; /* 8px */
}
```

### Px (Para Tamanhos Fixos)

Use `px` apenas para elementos que devem ter tamanho fixo:

```css
.border {
  border-width: 1px; /* Sempre 1px, não escala */
}
```

## Exemplos de Uso

### Padding

```tsx
// ✅ DO: Use tokens de espaçamento
<div className="p-4">Conteúdo</div> // padding: 1rem (16px)

// ✅ DO: Use classes Tailwind
<div className="px-3 py-2">Conteúdo</div> // padding: 0.75rem 0.5rem
```

### Margin

```tsx
// ✅ DO: Use tokens consistentes
<div className="mb-4">Conteúdo</div> // margin-bottom: 1rem

// ✅ DO: Espaçamento entre elementos
<div className="space-y-4">
  <div>Item 1</div>
  <div>Item 2</div>
</div>
```

### Gap

```tsx
// ✅ DO: Gap em flex/grid
<div className="flex gap-2">
  <Button>Botão 1</Button>
  <Button>Botão 2</Button>
</div>
```

## Diretrizes de Espaçamento

### Espaçamento Interno de Componentes

- **Componentes pequenos**: 4-8px (xs-sm)
- **Componentes médios**: 12-16px (md)
- **Componentes grandes**: 24-32px (lg-xl)

### Espaçamento Externo de Componentes

- **Entre elementos relacionados**: 8-12px
- **Entre seções**: 24-32px
- **Entre seções principais**: 48-64px

### Espaçamento de Texto

- **Altura de linha**: 1.5 (24px para fonte de 16px)
- **Espaçamento entre parágrafos**: 16px (1rem)
- **Margem de títulos**: 24px (1.5rem)

## Boas Práticas

1. **Use a escala modular** - Sempre múltiplos de 4px
2. **Mantenha consistência** - Use os mesmos espaçamentos em contextos similares
3. **Considere hierarquia** - Elementos mais importantes podem ter mais espaço
4. **Teste em diferentes tamanhos** - Espaçamentos podem parecer diferentes em mobile/desktop
5. **Use as cores do tema** - Represente espaçamentos visualmente com as cores do Ciberso-UI
