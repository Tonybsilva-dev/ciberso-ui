# Units & Measurements

Unidades e medidas do sistema de espaçamento do Ciberso-UI Design System.

## Base Unit

O sistema utiliza **4px (0.25rem)** como unidade base. Todos os espaçamentos são múltiplos desta unidade.

## Spacing Scale

### Semantic Spacing

Espaçamentos semânticos para uso em componentes:

<div style={{ display: 'grid', gridTemplateColumns: 'repeat(4, 1fr)', gap: '1rem', marginTop: '2rem' }}>
  {Object.entries(spacing).map(([key, value]) => {
    const sizeInPx = parseFloat(value.replace('rem', '')) * 16;
    return (
      <div key={key} style={{ textAlign: 'center' }}>
        <div
          style={{
            width: '100%',
            height: value,
            backgroundColor: '#007BFF',
            borderRadius: '4px',
            marginBottom: '0.5rem',
          }}
        />
        <div style={{ fontSize: '12px', fontWeight: 'bold', textTransform: 'uppercase' }}>{key}</div>
        <div style={{ fontSize: '11px', color: '#6b7280' }}>{value}</div>
        <div style={{ fontSize: '10px', color: '#9ca3af' }}>{sizeInPx}px</div>
      </div>
    );
  })}
</div>

## Units

### Rem (Recommended)

Use `rem` para espaçamentos que devem escalar com o tamanho da fonte do usuário:

```css
.component {
  padding: 1rem; /* 16px */
  margin: 0.5rem; /* 8px */
}
```

### Px (For Fixed Sizes)

Use `px` apenas para elementos que devem ter tamanho fixo:

```css
.border {
  border-width: 1px; /* Sempre 1px, não escala */
}
```

## Usage Examples

### Padding

```tsx
// ✅ DO: Use tokens de espaçamento
<div className="p-4">Content</div> // padding: 1rem (16px)

// ✅ DO: Use classes Tailwind
<div className="px-3 py-2">Content</div> // padding: 0.75rem 0.5rem
```

### Margin

```tsx
// ✅ DO: Use tokens consistentes
<div className="mb-4">Content</div> // margin-bottom: 1rem

// ✅ DO: Espaçamento entre elementos
<div className="space-y-4">
  <div>Item 1</div>
  <div>Item 2</div>
</div>
```

### Gap

```tsx

```

## Spacing Guidelines

### Component Internal Spacing

- **Small components**: 4-8px (xs-sm)
- **Medium components**: 12-16px (md)
- **Large components**: 24-32px (lg-xl)

### Component External Spacing

- **Between related elements**: 8-12px
- **Between sections**: 24-32px
- **Between major sections**: 48-64px

### Text Spacing

- **Line height**: 1.5 (24px para 16px font)
- **Paragraph spacing**: 16px (1rem)
- **Heading margin**: 24px (1.5rem)

## Best Practices

1. **Use a escala modular** - Sempre múltiplos de 4px
2. **Mantenha consistência** - Use os mesmos espaçamentos em contextos similares
3. **Considere hierarquia** - Elementos mais importantes podem ter mais espaço
4. **Teste em diferentes tamanhos** - Espaçamentos podem parecer diferentes em mobile/desktop
