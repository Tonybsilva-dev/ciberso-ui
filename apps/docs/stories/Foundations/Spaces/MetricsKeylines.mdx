# Metrics & Keylines

Métricas e linhas guia para alinhamento e estrutura no Ciberso-UI Design System.

## Keylines

Linhas guia invisíveis que ajudam a alinhar elementos e criar estrutura visual consistente.

### Baseline Grid

Grid de baseline baseado em 4px para alinhamento vertical:

<div style={{ position: 'relative', border: '1px solid #e5e7eb', borderRadius: '8px', padding: '2rem', backgroundColor: '#fff', marginTop: '2rem' }}>
  {/* Grid lines */}
  {Array.from({ length: 20 }, (_, i) => (
    <div
      key={i}
      style={{
        position: 'absolute',
        top: `${i * 4}px`,
        left: 0,
        right: 0,
        height: '1px',
        backgroundColor: i % 4 === 0 ? '#e5e7eb' : '#f3f4f6',
        opacity: 0.5,
        pointerEvents: 'none',
      }}
    />
  ))}
  
  {/* Sample content aligned to grid */}
  <div style={{ position: 'relative', zIndex: 1 }}>
    <h2 style={{ fontSize: '24px', lineHeight: '32px', marginTop: '0', marginBottom: '16px' }}>
      Heading Example
    </h2>
    <p style={{ fontSize: '16px', lineHeight: '24px', marginBottom: '16px' }}>
      This paragraph is aligned to the 4px baseline grid. The line height of 24px ensures proper vertical rhythm.
    </p>
    <p style={{ fontSize: '16px', lineHeight: '24px', marginBottom: '0' }}>
      Multiple paragraphs maintain consistent spacing, creating a harmonious reading experience.
    </p>
  </div>
</div>

## Alignment Keylines

### Text Alignment

- **Left align**: Padrão para textos longos
- **Center align**: Títulos e elementos destacados
- **Right align**: Números e dados tabulares

### Component Alignment

- **Vertical center**: Ícones com texto
- **Baseline align**: Texto em diferentes tamanhos
- **Edge align**: Elementos nas bordas

## Measurement Guidelines

### Minimum Touch Target

- **Mobile**: 44px × 44px (11 × 4px)
- **Desktop**: 40px × 40px (10 × 4px)

### Content Width

- **Mobile**: Padding lateral de 16px
- **Tablet**: Padding lateral de 24px
- **Desktop**: Max-width de 1200px com padding de 32px

### Section Spacing

- **Between sections**: 48-64px
- **Within sections**: 24-32px
- **Between related items**: 16px

## Best Practices

1. **Use keylines consistentemente** - Mantenha alinhamento visual
2. **Respeite métricas mínimas** - Touch targets e espaçamentos mínimos
3. **Teste visualmente** - Verifique alinhamento em diferentes tamanhos
4. **Documente exceções** - Se precisar quebrar o grid, documente o motivo
