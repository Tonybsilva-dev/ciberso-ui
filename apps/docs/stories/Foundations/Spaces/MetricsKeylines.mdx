# Métricas e Linhas Guia

Métricas e linhas guia para alinhamento e estrutura no Ciberso-UI Design System, inspirado no **Cloude**.

## Linhas Guia

Linhas guia invisíveis que ajudam a alinhar elementos e criar estrutura visual consistente.

### Grid de Baseline

Grid de baseline baseado em 4px para alinhamento vertical:

<div style={{ position: 'relative', border: '1px solid #dad9d4', borderRadius: '8px', padding: '2rem', backgroundColor: '#faf9f5', marginTop: '2rem' }}>
  {/* Grid lines */}
  {Array.from({ length: 20 }, (_, i) => (
    <div
      key={i}
      style={{
        position: 'absolute',
        top: `${i * 4}px`,
        left: 0,
        right: 0,
        height: '1px',
        backgroundColor: i % 4 === 0 ? '#dad9d4' : '#ede9de',
        opacity: 0.5,
        pointerEvents: 'none',
      }}
    />
  ))}
  
  {/* Sample content aligned to grid */}
  <div style={{ position: 'relative', zIndex: 1 }}>
    <h2 style={{ fontSize: '24px', lineHeight: '32px', marginTop: '0', marginBottom: '16px', color: '#3d3929' }}>
      Exemplo de Título
    </h2>
    <p style={{ fontSize: '16px', lineHeight: '24px', marginBottom: '16px', color: '#3d3929' }}>
      Este parágrafo está alinhado ao grid de baseline de 4px. A altura de linha de 24px garante ritmo vertical adequado.
    </p>
    <p style={{ fontSize: '16px', lineHeight: '24px', marginBottom: '0', color: '#3d3929' }}>
      Múltiplos parágrafos mantêm espaçamento consistente, criando uma experiência de leitura harmoniosa.
    </p>
  </div>
</div>

## Linhas Guia de Alinhamento

### Alinhamento de Texto

- **Alinhamento à esquerda**: Padrão para textos longos
- **Alinhamento central**: Títulos e elementos destacados
- **Alinhamento à direita**: Números e dados tabulares

### Alinhamento de Componentes

- **Centro vertical**: Ícones com texto
- **Alinhamento de baseline**: Texto em diferentes tamanhos
- **Alinhamento de borda**: Elementos nas bordas

## Diretrizes de Medição

### Área Mínima de Toque

- **Mobile**: 44px × 44px (11 × 4px)
- **Desktop**: 40px × 40px (10 × 4px)

### Largura de Conteúdo

- **Mobile**: Padding lateral de 16px
- **Tablet**: Padding lateral de 24px
- **Desktop**: Max-width de 1200px com padding de 32px

### Espaçamento entre Seções

- **Entre seções**: 48-64px
- **Dentro de seções**: 24-32px
- **Entre itens relacionados**: 16px

## Boas Práticas

1. **Use linhas guia consistentemente** - Mantenha alinhamento visual
2. **Respeite métricas mínimas** - Áreas de toque e espaçamentos mínimos
3. **Teste visualmente** - Verifique alinhamento em diferentes tamanhos
4. **Documente exceções** - Se precisar quebrar o grid, documente o motivo
5. **Use as cores do tema** - Represente métricas visualmente com as cores do Ciberso-UI
