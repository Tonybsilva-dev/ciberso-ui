# Spaces

Sistema de espaçamento do Ciberso-UI Design System.

## Visão Geral

O sistema de espaçamento do Ciberso-UI é baseado em uma escala modular de **4px**, garantindo consistência e harmonia visual em todos os componentes.

## Princípios

- **Modularidade**: Todos os espaçamentos são múltiplos de 4px
- **Consistência**: Mesma escala em todo o sistema
- **Hierarquia**: Espaçamentos maiores para elementos mais importantes
- **Responsividade**: Adaptação em diferentes tamanhos de tela

## Estrutura

Esta seção contém as seguintes páginas:

- **Unidades e Medidas**: Unidades e medidas do sistema
- **Métricas e Linhas Guia**: Métricas e linhas guia para alinhamento
