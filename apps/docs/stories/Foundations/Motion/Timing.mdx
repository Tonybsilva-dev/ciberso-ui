## Usage Guidelines

### Fast (150ms)
Use para micro-interactions e feedback imediato:

- Hover effects
- Tap/press feedback
- Focus rings
- Tooltip appearance

```tsx
<motion.button
  whileHover={{ scale: 1.05 }}
  transition={{ duration: 0.15 }} // fast
>
  Button
</motion.button>
```

### Normal (300ms)
Use para transições padrão e mudanças de estado:

- Component state changes
- Modal open/close
- Dropdown animations
- Form field transitions

```tsx
<motion.div
  animate={{ opacity: isOpen ? 1 : 0 }}
  transition={{ duration: 0.3 }} // normal
>
  Content
</motion.div>
```

### Slow (500ms)
Use para transições de página e animações complexas:

- Page transitions
- Complex morphing
- Multi-step animations
- Stagger animations

```tsx
<motion.div
  animate={{ x: 100 }}
  transition={{ duration: 0.5 }} // slow
>
  Content
</motion.div>
```

### Slower (750ms)
Use para animações muito complexas:

- SVG morphing
- Complex path animations
- Elaborate transitions

## Stagger Animations

Para animar múltiplos elementos em sequência:

```tsx
const container = {
  hidden: { opacity: 0 },
  show: {
    opacity: 1,
    transition: {
      staggerChildren: 0.1, // 100ms entre cada elemento
    },
  },
};

const item = {
  hidden: { opacity: 0, y: 20 },
  show: { opacity: 1, y: 0 },
};

<motion.div variants={container} initial="hidden" animate="show">
  {items.map((item) => (
    <motion.div key={item.id} variants={item}>
      {item.content}
    </motion.div>
  ))}
</motion.div>
```

## Timing Best Practices

1. **Mantenha animações curtas** - Usuários esperam feedback rápido
2. **Use delays com moderação** - Apenas quando necessário para clareza
3. **Considere o contexto** - Animações de página podem ser mais longas
4. **Teste a percepção** - Durações podem parecer diferentes em contextos diferentes
